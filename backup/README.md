# データベースバックアップ機能

このプロジェクトには、データベースの自動バックアップと手動バックアップ機能が実装されています。

## 機能

1. **自動バックアップ**: 1分ごとにデータベースを自動的にバックアップ
2. **手動バックアップ**: 管理者ダッシュボードから手動でバックアップを作成
3. **バックアップファイル管理**: 最新2ファイルのみを保持し、古いファイルは自動削除
4. **データベース復元**: バックアップファイルからデータベースを復元

## 使用方法

### 自動バックアップの開始

自動バックアップを開始するには、以下のコマンドを実行します：

```bash
# TypeScriptを直接実行する場合
npx ts-node scripts/backup-cron.ts

# または、pm2などのプロセスマネージャーを使用
pm2 start scripts/backup-cron.ts --interpreter npx --interpreter-args ts-node
```

### 手動バックアップ

1. 管理者ダッシュボードにログイン
2. 右上の「バックアップ」ボタンをクリック
3. 「新規バックアップ作成」ボタンをクリック

### データベース復元

1. 管理者ダッシュボードにログイン
2. 右上の「バックアップ」ボタンをクリック
3. 復元したいバックアップファイルを選択
4. 「選択したファイルで復元」ボタンをクリック
5. 警告メッセージを確認し、「確認」ボタンをクリック

**注意**: データベースの復元は、最終バックアップ以降から現在までのデータを削除します。復元前に必ず最新のバックアップを作成してください。

## バックアップファイルの保存場所

バックアップファイルは `backup/` ディレクトリに保存されます。

ファイル名の形式: `backup_YYYY-MM-DD_HH-MM-SS.sql`

## 要件

- PostgreSQLの `pg_dump` と `psql` コマンドがシステムにインストールされている必要があります
- データベースへの接続権限が必要です

## トラブルシューティング

### バックアップが失敗する場合

1. PostgreSQLのコマンドラインツールがインストールされているか確認
2. データベース接続情報（環境変数）が正しく設定されているか確認
3. `backup/` ディレクトリへの書き込み権限があるか確認

### 復元が失敗する場合

1. バックアップファイルが存在するか確認
2. データベースへの接続権限があるか確認
3. データベースが他のプロセスで使用されていないか確認
